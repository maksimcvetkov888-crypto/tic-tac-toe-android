# 🎮 Tic-Tac-Toe (Крестики-Нолики для Android)

Красивая и быстрая нативная игра **«Крестики-Нолики»** для двух игроков на одном мобильном устройстве (Hot-Seat).

---

## 📱 Особенности игры
- **Режим на двоих**: Играйте вдвоём на одном экране смартфона или планшета по очереди.
- **Индикация ходов**: Всегда видно, чей сейчас ход (Игрок 1 — X, Игрок 2 — O).
- **Счётчик матчей**: Ведётся постоянный счёт побед каждого игрока и количества ничьих.
- **Тактильная отдача**: Приятная вибрация при каждом нажатии ячейки и особая вибрация при победе.
- **Победная анимация**: Подсвечивается выигрышная линия с плавной анимацией масштабирования.
- **Тёмная тема Material 3**: Высококонтрастная палитра, комфортная для глаз и экономичная для AMOLED-экранов.

---

## 🛠 Технологический стек
- **Язык**: Kotlin
- **Архитектура**: Clean MVC / Activity + Game State Engine
- **UI**: Android Material 3 Components, ViewBinding, Vector Drawables
- **Android SDK**: minSdk 24 (Android 7.0+), targetSdk 34 (Android 14/15)
- **CI/CD**: GitHub Actions автоматическая сборка и публикация релизов

---

## 💻 Сборка из исходников
```bash
gradle assembleRelease
```
Собранный APK появится в папке `app/build/outputs/apk/release/`.
